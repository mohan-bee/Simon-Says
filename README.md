# Sticky Notes Project

A simple and interactive sticky notes application built with HTML, CSS, and JavaScript. This project allows you to create, edit, and delete notes on the fly while persisting your data locally so that your notes remain even after refreshing the browser.

## Features

- **Create Notes:** Add new sticky notes with a single click.
- **Edit Notes:** Click on any note to edit its content.
- **Delete Notes:** Remove unwanted notes easily.
- **Local Storage Persistence:** Your notes are saved in the browser's local storage.
- **Responsive Design:** Enjoy a seamless experience on both desktop and mobile devices.
